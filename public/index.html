    How it works

    £10 spent = 1 lookup credit

    Earning credits

    Credits are calculated per order only — leftover spend does not carry over. Example: a £15 order awards 1 credit; the remaining £5 is not saved for the next order.

    Orders under £10 award no credits. A £20 order awards 2 credits.

    Using credits

    Each live registration lookup uses 1 credit. If you have already looked up that plate recently (within 7 days), it’s served from cache and doesn’t use a credit.

    You can check your remaining credits on this Registration Check page when logged in.
